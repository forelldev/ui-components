# ⚽ Gol Upload

Un componente de carga de archivos (*file upload*) con animación de tiro a puerta al arrastrar y soltar (*drag & drop*).

<img width="600" height="800" alt="video1" src="https://github.com/user-attachments/assets/91426eaa-0aaf-4e47-8a06-5cbce734cbd6" />


## ⚡ Tecnologías
* **HTML5 & CSS3** (Animaciones nativas con Keyframes)
* **Tailwind CSS** (vía CDN)
* **Vanilla JavaScript** (Gestión de eventos drag & drop y cola de archivos)


## 🚀 Cómo ejecutar
Simplemente clona este repositorio y abre el archivo `index.html` en tu navegador:

```bash
# Abrir directamente en Linux / macOS / Windows
open gol-upload/index.html
```

O desde la carpeta:

```bash
cd gol-upload && open index.html
```
