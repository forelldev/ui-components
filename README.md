# Componentes UI

Colección de componentes interactivos creados con tecnologías web estándar.

## ⚡ Tecnologías

Todos los componentes están desarrollados con:

- **HTML5** – Estructura semántica y accesible.
- **CSS3** – Estilos nativos con animaciones y transiciones.
- **Tailwind CSS** (vía CDN) – Utilidades para agilizar el diseño.
- **Vanilla JavaScript** – Lógica sin frameworks o librerías externas.

## 📂 Componentes

### 1. Gol Upload (`gol-upload/`)

Componente de carga de archivos (*file upload*) con animación de tiro a puerta al arrastrar y soltar (*drag & drop*).

**Cómo usarlo:**

```bash
open gol-upload/index.html
```

### 2. Button Modes (`button-modes/`)

Interruptor tipo bombillo con cuerda (*pull-chain*). Al jalar la cuerda hacia abajo cambia automáticamente entre modo oscuro (negro) y modo claro (blanco), con movimiento natural de la cuerda.

**Cómo usarlo:**

```bash
open button-modes/index.html
```

## 🚀 Ejecución rápida

Puedes abrir cualquier componente directamente en tu navegador:

```bash
# Gol Upload
cd gol-upload && open index.html

# Button Modes
cd button-modes && open index.html
```
